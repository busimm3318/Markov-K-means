# 연구 계획: 비수렴 벡터의 Markov 연쇄 기반 클러스터 편입 (Markov-K-means)

## 0. 요약

K-means를 충분히 반복(≥10회)해서 대표점(centroid)은 거의 움직이지 않는데, 소수의 벡터 xᵢ만 클러스터 주소가 계속 바뀌어 수렴하지 않는 경우가 있다. 이 소수를 위해 전체 데이터에 대한 반복을 계속하는 대신, 다음 두 단계를 적용한다.

1. 각 xᵢ의 반복별 클러스터 주소 이력으로 상태전이행렬을 만든다. 그 Markov 연쇄의 정상분포로 편입할 클러스터를 정한다.
2. 정상분포가 [0.5, 0.5]처럼 나오면 이산적으로 한 곳에 넣지 않는다. 대신 연속적 소속도(0.5 / 0.5)로 해석한다.

이 연구는 세 가지 질문에 답한다.

| 질문 | 내용 |
|---|---|
| **RQ1 (계산량)** | 이 알고리즘은 수렴까지 반복하는 것에 비해 계산 자원을 얼마나 줄이는가? |
| **RQ2 (오차)** | 다른 방법론과 비교해 오차는 어떠한가? |
| **RQ3 (연속 해석)** | 연속적 해석은 얼마나 타당하고 유용한가? |

## 1. 문제 정의와 알고리즘의 정식화

### 1.1 기호

* 데이터 X = {x₁,…,x_N} ⊂ ℝ^d
  * N은 벡터 개수, d는 벡터 차원이다. 요청서의 "벡터의 크기 n"은 d에 해당한다.
* 클러스터 수 k, 대표점 c₁,…,c_k.
* ℓᵢ(t) ∈ {1,…,k}: t번째 대표점 갱신 직후 xᵢ의 클러스터 주소.
* T₀: Markov 편입으로 전환하는 반복 횟수(전제상 T₀ ≥ 10).
* W: 전이를 셀 이력 창(window)의 길이.
* T_conv: 라벨 변화가 0이 될 때까지의 반복 횟수(완전 수렴).

### 1.2 제안 알고리즘 (MK: Markov-K-means 편입)

**A. 기록.** K-means를 T₀회 수행하면서 최근 W회의 라벨을 링 버퍼(N×W, int16)에 기록한다.
* 추가 메모리: N·W·2바이트. 예를 들어 N=10⁶, W=10이면 20 MB다.

**B. 비수렴 집합 U 검출.** 창 안에서 라벨이 한 번이라도 바뀐 점을 U로 둔다: U = {i : ℓᵢ(t) ≠ ℓᵢ(T₀), ∃t ∈ [T₀−W, T₀]}.
* 다른 검출 규칙도 실험한다(4.5절).

**C. 점별 Markov 연쇄 추정.**
1. i ∈ U마다 방문한 상태 집합 Sᵢ(보통 2~3개 클러스터)에 대해 전이횟수 n_i(a→b)를 센다.
2. Dirichlet 평활(α)을 적용해 Pᵢ(a,b) = (n_i(a→b)+α) / Σ_b(n_i(a→b)+α)를 만든다.
3. 정상분포 πᵢ (πᵢ = πᵢPᵢ)를 구한다.
   * 2상태: 닫힌 형태 π = (p_ba, p_ab)/(p_ab+p_ba).
   * 3상태 이상: 고유벡터로 구한다.
   * 흡수(absorbing) 상태, 주기(periodic) 연쇄, 마지막 상태의 출력 전이가 없는 경우는 4.5절의 규칙으로 다룬다.

**D. 편입.**
* **MK-hard:** ℓᵢ = argmax πᵢ.
* **MK-soft:** 소속도 wᵢⱼ = πᵢ(j). 대표점은 가중평균 c_j = Σᵢ wᵢⱼ xᵢ / Σᵢ wᵢⱼ로 한 번 갱신한다.
* 안정점(i ∉ U)은 wᵢ = one-hot(ℓᵢ(T₀))로 둔다.

### 1.3 계산량 모형

| 단계 | 비용 |
|---|---|
| K-means T₀회 | T₀ · N · k · d (Lloyd 기준) |
| 이력 기록 | N · W 정수 쓰기 (무시 가능) |
| Markov 추정 | Σ_{i∈U} (W + |Sᵢ|³) — d, k와 무관 |
| 대표점 1회 갱신 | N · d |
| **비교: 완전 수렴** | T_conv · N · k · d |

따라서 이론적 절감률은 Lloyd 기준 약 (T_conv − T₀)/T_conv다.
* 다만 Hamerly·Elkan·Yinyang 같은 정확(exact) 가속법을 쓰면 후반 반복은 이미 대부분의 점을 건너뛰어 싸다.
* 그래서 **공정한 비교 기준선은 "가속된 정확 K-means로 끝까지 수렴"**이다. 실제 절감은 그보다 작을 수 있다(RQ1에서 측정).

### 1.4 Markov 정상분포 ≠ 단순 빈도

U의 점은 이력이 짧다(관측 전이 수 ≈ W). 그래서 πᵢ가 단순 빈도(다수결)와 다른지가 핵심이다.

* **표류(drift) 예:** 이력이 A A A A A B B B이면 빈도는 A가 5/8로 우세하다. 그런데 전이는 A→A 4, A→B 1, B→B 2이고 B→A는 없다. B가 흡수 상태이므로 π = [0, 1]이 되어 **B**로 편입한다.
  * Markov 해석은 빈도처럼 과거를 묘사하지 않는다. 대신 이동의 **방향과 극한**을 외삽한다.
* **진동 예:** A B A B A B는 주기 연쇄다. Cesàro 평균 의미의 정상분포 π = [0.5, 0.5]가 존재하고 빈도와 같다.
* 평활 α를 적용하면 이 두 극단 사이를 연속적으로 잇는다. α를 얼마로 두어야 하는지는 실험으로 정한다.

## 2. 예비 관찰 (Exp 0, `experiments/exp0_pilot.py`)

정확한 Lloyd 알고리즘(k-means++ 초기화, 라벨 변화 0까지)에서 점별 라벨 이력을 전부 기록했다(T₀=10). 원자료는 `experiments/results/exp0_pilot.txt`에 있다.

| 데이터 | 수렴 반복 | T₀ 이후 패스 비중 | T₀ 이후 라벨이 바뀐 점 | 최종 라벨 ≠ T₀ 라벨 | T₀ 이후 전환 횟수(중앙값) | T₀ 라벨로 되돌아온 비율 |
|---|---|---|---|---|---|---|
| 잘 분리된 blobs (N=5만, d=16, k=50) | 19–26 | 47–62% | 0.11–0.22% | 0.11–0.20% | 1 | 0.02–0.06 |
| 겹친 blobs (N=5만, d=16, k=50) | 48–54 | 79–82% | 9.0–14.1% | 8.1–13.0% | 1 | 0.08–0.10 |
| uniform (N=5만, d=8, k=50) | 135–212 | 93–95% | 45–50% | 40–44% | 1 | 0.11–0.12 |
| Fashion-MNIST (N=2만, d=784, k=50) | 84–99 | 88–90% | 17–21% | 16–20% | 1 | 0.04–0.05 |
| BIRCH3 (N=10만, d=2, k=100) | 123–164 | 92–94% | 12–14% | 11–13% | 1 | 0.05–0.07 |

다음은 T₀ 이전 W회 안에 바뀐 점을 U로 잡았을 때, T₀ 이후에 바뀔 점을 얼마나 맞히는지다.

| 데이터 | W=3 재현율 / 정밀도 | W=10 재현율 / 정밀도 |
|---|---|---|
| 잘 분리된 blobs | 0.04–0.06 / 0.03–0.10 | 0.21–0.29 / 0.01–0.02 |
| 겹친 blobs | 0.10–0.16 / 0.18–0.29 | 0.75–0.78 / 0.11–0.17 |
| Fashion-MNIST | 0.07–0.09 / 0.20–0.30 | 0.48–0.51 / 0.19–0.24 |
| BIRCH3 | 0.03–0.04 / 0.22–0.23 | 0.22–0.25 / 0.17–0.25 |

Mini-batch K-means(배치 1024)도 측정했다. 대표점 이동이 작아진 뒤에도 약 3%의 점이 라벨을 바꾼다. 이 점들의 전환 횟수 중앙값은 1, 최대는 5~10이다.

### 2.1 시사점 (계획에 반영)

1. **"아무리 반복해도 수렴하지 않는다"는 정확한 Lloyd에서는 성립하지 않는다.**
   * 라벨이 바뀔 때마다 목적함수(SSE)가 엄격히 감소하고, 가능한 분할은 유한하다(동점 규칙이 일관될 때). 그래서 Lloyd는 유한 번 안에 반드시 수렴한다.
   * 실제로 나타나는 현상은 **긴 꼬리**다. 전체 패스의 47~95%가 T₀ 이후에 쓰이고, 그 동안 바뀌는 점은 소수다.
   * 영구적인 진동은 다음 경우에 생긴다:
     * Mini-batch 또는 상수 학습률 SGD 같은 확률적 변형
     * 비동기·분산 구현
     * 부동소수점 동점
   * 따라서 연구 대상을 **(a) 정확 Lloyd의 꼬리 절단**과 **(b) 확률적 K-means의 지속 진동** 두 체제로 나눈다.
2. **정확 Lloyd에서 비수렴 점은 대부분 "진동"이 아니라 "한 번 표류"한다.**
   * T₀ 이후 전환은 중앙값 1회이고, T₀ 라벨로 돌아오는 점은 2~12%뿐이다.
   * 이 경우 빈도 기반 판단은 옛 라벨을 고르게 된다. 1.4절의 흡수 상태 외삽이 Markov 방식의 잠재적 장점이다.
3. **T₀ 이전 이력만으로는 T₀ 이후에 바뀔 점을 잘 예측하지 못한다.**
   * 재현율은 W=3에서 0.03–0.16, W=10에서 0.21–0.78이다.
   * 많은 점이 T₀ 시점에 아직 움직이기 전이기 때문이다.
   * 이것이 제안법의 가장 큰 위험이다. 대응책은 다음과 같다:
     * 점별 전이를 클러스터 쌍별로 모은 사전분포(경험적 Bayes, P3)
     * 마진(d₂−d₁) 기반 U 검출
     * T₀ 이후 정확 가속법으로 짧게 관측을 늘리는 하이브리드(P4)
4. **"소수"라는 전제가 맞는 체제는 제한적이다.** 잘 분리된 데이터에서는 0.1–0.2%지만, 실데이터(Fashion-MNIST)에서는 약 20%다. 결과는 분리도별로 나눠 보고한다.

## 3. 연구 질문과 가설

| 질문 | 가설 | 판정 기준 |
|---|---|---|
| RQ1 계산량 | H1a: 완전 수렴 Lloyd 대비 거리 계산·시간을 (T_conv−T₀)/T_conv 가까이 절감한다. | 절감률의 평균과 95% 신뢰구간 |
| | H1b: 가속 정확법(Hamerly/Yinyang) 대비 절감은 H1a보다 작지만 양(+)이다. | 동일 |
| RQ2 오차 | H2a: MK-hard는 "T₀에서 멈추고 현재 라벨 유지"(B1)와 다수결(B3)보다 수렴해(reference)와 덜 불일치한다. | 쌍대 Wilcoxon 검정, p<0.05 |
| | H2b: MK-hard의 오차는 최근접 재배정(B2)·활성집합 정제(B4)와 비교 가능한 수준이다. | 동일 |
| RQ3 연속 해석 | H3a: 합성 GMM에서 πᵢ는 참 사후확률 p(zᵢ=j\|xᵢ)와 양의 상관을 갖고, 보정(calibration) 오차가 낮다. | ECE, Brier, TV 거리 |
| | H3b: πᵢ의 엔트로피는 오분류 위험이 큰 점을 식별한다. | AUROC > 0.5, 대안 대비 비교 |
| | H3c: MK-soft로 대표점을 갱신하면 hard 갱신보다 참 대표점에 가깝다. | 대표점 오차 |

H2와 H3의 결과가 부정적이어도 그대로 보고한다. 예를 들어 πᵢ가 결국 마진의 잡음 섞인 함수에 불과하다면, 닫힌 형태의 마진 기반 소속도가 더 싸고 정확하다는 결론도 유효한 결과다.

## 4. 실험 설계

### 4.1 데이터

| 종류 | 구성 | 목적 |
|---|---|---|
| 합성 GMM | 등방 가우시안 혼합. 분리도 sep ∈ {1, 1.5, 2, 3, 4}, N ∈ {10⁴, 10⁵, 10⁶}, d ∈ {2, 16, 128, 1024}, k ∈ {10, 50, 200} | 참 라벨·참 사후확률을 알 수 있어 RQ2·RQ3의 정답 기준이 된다. 분리도 sweep으로 "소수 비수렴" 전제의 범위를 확인한다. |
| Fashion-MNIST | 60000 × 784 | 고차원 실데이터. 클래스 라벨로 외부 평가 |
| BIRCH 1–3 | 100000 × 2, 100개 군집 | 대규모 N, 저차원, 참 군집 구조 |
| (추가 후보) 대규모 임베딩 | 접근 가능 여부 확인 후 결정 (네트워크 정책상 GitHub raw만 확인됨) | "N·d 매우 큼" 조건 검증 |

* 메모리 한도: 15 GB RAM, 4 CPU.
* 그래서 N=10⁶은 d ≤ 128(float64 약 1 GB)까지만 쓴다.
* d=1024는 N ≤ 2×10⁵ 또는 float32로 제한한다.

### 4.2 라벨 이력을 만드는 기반 알고리즘 (두 체제)

1. **정확 Lloyd**: 결정적이고 표류 위주다(2절). 주 대상 체제다.
2. **Lloyd + 허용오차 조기종료**: scikit-learn 기본값(tol=1e-4, 대표점 이동 기준)으로 실무 상황을 재현한다.
3. **Mini-batch K-means** (Sculley 2010, 학습률 1/count 감소): 확률적이고 느리게 안정된다.
4. **상수 학습률 mini-batch/SGD**: 대표점이 최적점 주변에서 지터한다. 지속 진동 체제로, 정상분포 해석이 가장 자연스럽다.

### 4.3 비교 방법

| ID | 방법 | 설명 | 역할 |
|---|---|---|---|
| M0 | Lloyd 완전 수렴 | 라벨 변화 0까지 반복 | 기준해(reference)이자 계산량 상한 |
| M0′ | Hamerly / Yinyang 완전 수렴 | M0과 결과가 동일한 정확 가속법 | **공정한 계산량 기준선** |
| B1 | T₀ 정지 + 현재 라벨 | 아무것도 안 함 | 오차 상한 |
| B2 | T₀ 정지 + 최근접 재배정 | U(또는 전체)를 현재 대표점에 1회 재배정 | 가장 싼 대안 |
| B3 | 다수결 | 창 W 안의 라벨 빈도 최빈값 | "빈도 vs Markov" 대조군 |
| B4 | 활성집합 정제 | 안정점 고정, U만 Lloyd 반복(대표점 증분 갱신) | 국소 반복 대안 |
| B5 | Hartigan 이동 | U에 대해 목적함수를 줄이는 단일점 이동 | 국소 최적화 대안 |
| P1 | **MK-hard** | 점별 연쇄, argmax π | 제안법 |
| P2 | **MK-soft** | π를 소속도로 사용, 가중 대표점 1회 갱신 | 제안법(연속 해석) |
| P3 | MK + 공유 사전분포 | 클러스터 쌍별 전이를 모은 Dirichlet 사전분포로 점별 추정을 수축(경험적 Bayes) | 짧은 이력 문제 대응 확장 |
| P4 | MK 하이브리드 | T₀ 이후 정확 가속법으로 소수 반복을 더 관측한 뒤 편입 | 예측력 부족 대응 확장 |

RQ3의 연속 소속도 비교 대상:

| 비교 대상 | 비고 |
|---|---|
| 참 사후확률 | 합성 데이터에서만 가능 |
| GMM-EM 사후확률 | 공유 등방 분산, 최종 대표점으로 초기화 |
| Soft K-means | softmax(−β‖x−c‖²), β는 검증셋으로 조정 |
| Fuzzy c-means 소속도 | m=2, 최종 대표점 기준 |
| 마진 기반 소속도 | 상위 두 거리의 비율 |
| 부트스트랩 공동배정 빈도 | 합의 군집화 방식 |
| Mini-batch 라벨 빈도 | — |

### 4.4 평가 지표

**RQ1 계산량**
* 점–대표점 거리 계산 횟수(구현과 무관한 주 지표)
* 단일 스레드 벽시계 시간(JIT 예열 후, 3회 중 최소값)
* 데이터 패스 수
* 추가 메모리(이력 버퍼)
* 절감률은 M0 대비와 M0′ 대비를 모두 보고한다.

**RQ2 오차**
* 수렴해 M0 대비 라벨 불일치율(전체와 U 내부)
* 상대 SSE 증가 (SSE − SSE_ref)/SSE_ref
* 대표점 오차: 평균·최대 ‖c_j − c_j^ref‖, 평균 대표점 간 거리로 정규화
* ARI/NMI: 수렴해 대비, 그리고 참 라벨 대비
* M0은 국소최적해일 뿐 "진실"이 아니다. 그래서 참 라벨 대비 지표를 함께 보고한다.

**RQ3 연속 해석**
* *타당성:* 참 사후확률과의 TV 거리·KL, Brier 점수, 보정 오차 ECE와 신뢰도 도표(π=0.7인 점이 실제로 70% 확률로 그 클러스터에 속하는가).
* *대안과의 일치:* GMM·FCM·부트스트랩과의 상관(소속도 및 불확실성 순위의 Spearman 상관).
* *해상도 한계:* W회 관측으로 π가 가질 수 있는 값의 격자, 추정 표준오차, α 민감도.
* *유용성:*
  * 엔트로피(π)로 오분류 점 탐지(AUROC)
  * soft 대표점 갱신의 대표점 오차
  * 섭동(부트스트랩)에 대한 대표점 안정성
  * 하류 과제 예: Fashion-MNIST 클래스 예측의 선택적 정확도(불확실한 점 제외 시 정확도 향상)

### 4.5 변수 sweep 및 ablation

| 변수 | 값 |
|---|---|
| T₀ | {10, 15, 20, 30} |
| W | {3, 5, 10, 20} |
| 평활 α | {0, 0.1, 0.5, 1} |
| U 검출 규칙 | 창 내 변화 / 마진 임계값 / 둘의 결합 |

다음 규칙들도 ablation 대상이다.
* 흡수 상태 처리: 흡수 상태로 편입 vs α 평활
* 출력 전이 없는 마지막 상태: 자기전이 가정 vs 제거
* 주기 연쇄: Cesàro 평균

반복과 통계 방법은 다음과 같다.
* 각 설정은 초기화 시드 10개로 반복한다.
* 평균과 95% 신뢰구간을 보고한다.
* 방법 간 비교는 같은 시드끼리 쌍대 Wilcoxon 검정을 한다.

### 4.6 공정성 규칙

* 모든 방법은 같은 초기 대표점에서 시작한다.
* 정확 방법은 Lloyd와 라벨·대표점이 비트 단위로 같은지 테스트로 검증한다(`tests/test_exact_equivalence.py`).
* 거리 계산 횟수와 벽시계 시간을 따로 보고한다. 거리 계산 횟수는 GEMM(행렬곱) 구현의 효율 차이를 배제한다.
* 최대 반복은 1000으로 제한한다.
